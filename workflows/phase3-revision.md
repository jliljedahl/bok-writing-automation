# FAS 3: STRUKTURELL REVISION

**Tid:** 2-3 timmar per kapitel
**Agenter:** Ellis (utvecklingsredaktör) → Sage (revision)
**Input:** Draft v1
**Output:** Draft v2

---

## PROCESS

### Steg 1: Ellis granskar Draft v1 (1-1.5 timmar)

**Ellis läser och analyserar:**
1. Strukturell kvalitet
2. Karaktärsutveckling
3. Emotionell impact
4. Pacing
5. Show vs Tell balance

**Output:** Utvecklingsredaktion-rapport med:
- Betyg (X/10 per metrik)
- Vad fungerar bra ✅
- Vad behöver förbättras ⚠️
- Prioriterad TODO-lista för Sage
- Konkreta förslag

### Steg 2: Sage läser Ellis feedback (15 min)

**Sage:**
- Läser Ellis rapport noggrant
- Förstår prioriteringar (MÅSTE vs BORDE vs NICE TO HAVE)
- Planerar revisions-strategi

### Steg 3: Sage reviderar till Draft v2 (1-1.5 timmar)

**Sage fixar baserat på Ellis prioritering:**

**MÅSTE-fixes:**
- [ ] Strukturella problem
- [ ] Karaktär-inkonsistens
- [ ] Pacing-problem
- [ ] Plot logic-hål

**BORDE-fixes:**
- [ ] Show vs Tell-förbättringar
- [ ] Emotionella beats som inte landar
- [ ] Mindre pacing-justeringar

**NICE TO HAVE:**
- [ ] Språkpolering
- [ ] Mindre förbättringar

**Output:** Draft v2
- Strukturellt starkare
- Bättre pacing
- Fördjupade karaktärer
- Förbättrat språk

---

## FÖRVÄNTAT RESULTAT

**Kvalitetsförbättring:**
- Draft v1: Typiskt 7.0-7.5/10
- Draft v2: Typiskt 7.5-8.5/10
- **Förbättring: +0.3-0.5 poäng**
